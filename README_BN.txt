TL AI Assistant — Android Studio প্রজেক্ট (প্রাথমিক সংস্করণ)

এই ZIP-এ Android অ্যাপের সোর্স প্রজেক্ট আছে; এটি সরাসরি ইনস্টলযোগ্য APK নয়।

এখন যা আছে:
- বাংলা টেক্সট নির্দেশ
- Android Speech Recognizer ব্যবহার করে ভয়েস ইনপুট (ফোনে সমর্থন ও অনুমতি লাগবে)
- বাংলা টেক্সট-টু-স্পিচের চেষ্টা
- সেটিংস খোলা
- ক্যালকুলেটর খোলার চেষ্টা
- ব্যবহারকারীর বেছে দেওয়া ফাইল পিকার খোলা

এখনো নেই:
- পূর্ণ কথোপকথনমূলক AI মডেল / API
- ফোনের সব ফাইল নিজে নিজে পড়া বা পরিবর্তন করা
- সব অ্যাপ/সেটিংস নিয়ন্ত্রণ
- APK বিল্ড ও বাস্তব ফোনে পরীক্ষা

APK বানানোর জন্য:
1. কম্পিউটারে Android Studio ইনস্টল করো।
2. এই ZIP Extract করো।
3. Android Studio থেকে ফোল্ডারটি Open করো।
4. Gradle sync সম্পন্ন হতে দাও।
5. Build > Build Bundle(s) / APK(s) > Build APK(s) বেছে নাও।
6. বিল্ড সফল হলে Android Studio APK-এর অবস্থান দেখাবে।

নিরাপত্তা:
অ্যাপটি গোপনে ফাইল পড়ে না, কিছু মুছে না এবং নিজে নিজে মেসেজ পাঠায় না। ব্যবহারকারীর অনুমতি ছাড়া সংবেদনশীল কাজ করা উচিত নয়।
